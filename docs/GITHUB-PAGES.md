# GitHub Pages

Die **App** liegt auf GitHub Pages. Katalog und Bilder bleiben lokal und werden nicht committed.

**URL:** https://abx-git.github.io/C2/

Einmalig: **Settings → Pages → Source: GitHub Actions**

Nach `git push` auf `main` baut der Workflow die leere Galerie-App. Inhalt kommt weiter über den lokalen Editor und Deploy-Ordner.
